import { Palettes, Scale } from 'component/Wind';

`@plumeria/wind` provides Tailwind CSS design values as static tokens. The values are compiled into your styles at build time, so the package adds nothing to your bundle.

## Installation

```sh title="Terminal"
pnpm i -D @plumeria/wind
```

---

## Usage

```tsx title="Button.tsx"
import * as css from '@plumeria/core';
import * as t from '@plumeria/wind';

const styles = css.create({
  button: {
    paddingInline: t.spacing[4],
    fontSize: t.text.sm,
    color: t.slate[50],
    backgroundColor: t.blue[600],
    borderRadius: t.radius.md,
  },
});
```

The namespace name is up to you, and named imports work the same way.

Animations pair a keyframes export with its timing.

```tsx title="Spinner.tsx"
import * as css from '@plumeria/core';
import * as t from '@plumeria/wind';

const styles = css.create({
  spinner: {
    animation: `${t.spin} ${t.animate.spin}`,
  },
});
```
