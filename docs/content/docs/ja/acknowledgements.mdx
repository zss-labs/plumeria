## 参考にしたプロジェクト

- [Linaria](https://linaria.dev/) の、ランタイムを使わない設計
- [React Native](https://reactnative.dev/docs/stylesheet) の `StyleSheet.create` の書き方
- [React Native for Web](https://necolas.github.io/react-native-web/) の、CSS-in-JS からアトミック CSS を生成する仕組み
- [StyleX](https://stylexjs.com/) から Plumeria が受け継いだ設計の考え方
- [Tailwind CSS](https://tailwindcss.com/) の、`@plumeria/wind` に採用したデザイン値
