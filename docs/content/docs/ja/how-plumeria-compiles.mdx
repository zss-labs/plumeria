この例では、`Card.tsx` が `sx` に渡す `btn.base` の余白を、別のファイルで定義しています。Plumeria はビルド時にこの二つを結び付けます。

<img src="/compiler-architecture.svg" width={960} height={456} alt="button.ts で btn の base を探し、JSX と CSS に同じクラス名を出力する" />

## 定義を読み取る

スキャナーは `button.ts` の `css.create` を見つけ、スタイルオブジェクト全体のハッシュを計算します。次に二つの対応を記録します。一つはファイルパスと変数名（`…/button.ts-btn`）からハッシュ（`x2vyv31m`）への対応です。もう一つは、そのハッシュから `base` を含む定義への対応です。

## 使う場所にクラス名を入れる

`Card.tsx` を変換するとき、コンパイラは `btn` の import をたどって `button.ts` の定義を読みます。その中の `base` には `padding: 16` が一つだけあります。

この宣言から `xqqbxt1d` というクラスが生成されます。要素にはそのクラス名を入れ、CSS に `.xqqbxt1d { padding: 16px; }` を出力します。コンポーネントを描画する時点で、定義の探索はすでに完了しています。
