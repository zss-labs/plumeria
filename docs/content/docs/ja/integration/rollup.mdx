Rollup で [`@plumeria/unplugin`](https://www.npmjs.com/package/@plumeria/unplugin) を使う例は [`examples/example-rollup`](https://github.com/zss-labs/plumeria/tree/main/examples/example-rollup) にあります。Plumeria のスタイルを CSS に変換し、Rollup が出力する CSS ファイルに含めます。

[@plumeria/init](/ja/docs/api/migrate/init) を実行すると Rollup を検出し、必要な設定を書き込みます。以下は、同じ設定を手動で追加する手順です。

## インストール
```sh title="Terminal"
pnpm i -D @plumeria/unplugin
```

## プラグインを設定する
```js title="rollup.config.js"
import plumeria from '@plumeria/unplugin';
import resolve from '@rollup/plugin-node-resolve';
import commonjs from '@rollup/plugin-commonjs';
import replace from '@rollup/plugin-replace';
import esbuild from 'rollup-plugin-esbuild';
import postcss from 'rollup-plugin-postcss';

export default {
  input: 'src/index.tsx',
  output: {
    dir: 'dist',
    format: 'esm',
  },
  plugins: [
    plumeria.rollup(),
    postcss({ extract: true }),
    resolve({ extensions: ['.js', '.jsx', '.ts', '.tsx'] }),
    commonjs(),
    replace({
      'process.env.NODE_ENV': JSON.stringify('development'),
      preventAssignment: true,
    }),
    esbuild({
      include: /\.[jt]sx?$/,
      sourceMap: false,
      minify: false,
      target: 'es2022',
      jsx: 'automatic',
    }),
  ],
};
```

## sx の型を読み込む

`@plumeria/core` を入れただけでは JSX の prop の型は追加されません。プロジェクトで使う prop 名に合わせて型宣言を読み込みます。

標準の `sx` を使う場合は、パッケージ付属の型宣言を参照します。`src/` があればその中に、なければプロジェクトのルートに次のファイルを置きます。

```ts title="plumeria.d.ts"
/// <reference types="@plumeria/core/sx" />
```

`styleProp` を `'classStyle'` などに変えた場合は、プラグインの設定と同じ名前で型を宣言します。[prop の型宣言](/ja/docs/api/types/Style#スタイリング-prop-を宣言する-declaring-the-styling-prop)
