esbuild で [`@plumeria/unplugin`](https://www.npmjs.com/package/@plumeria/unplugin) を使う例は [`examples/example-esbuild`](https://github.com/zss-labs/plumeria/tree/main/examples/example-esbuild) にあります。Plumeria のスタイルを CSS に変換し、esbuild が出力する CSS ファイルに含めます。

[@plumeria/init](/ja/docs/api/migrate/init) を実行すると esbuild を検出し、必要な設定を書き込みます。以下は、同じ設定を手動で追加する手順です。

## インストール
```sh title="Terminal"
pnpm i -D @plumeria/unplugin
```

## プラグインを設定する
```ts title="scripts/build.js"
import esbuild from 'esbuild';
import plumeria from '@plumeria/unplugin';

esbuild
  .build({
    entryPoints: ['src/index.tsx'],
    bundle: true,
    outfile: 'dist/bundle.js',
    plugins: [
      plumeria.esbuild({
        include: /\.[jt]sx?$/,
      }),
    ],
    loader: {
      '.tsx': 'tsx',
      '.ts': 'ts',
    },
    format: 'esm',
    minify: false,
  })
  .catch(() => process.exit(1));
```

## sx の型を読み込む

`@plumeria/core` を入れただけでは JSX の prop の型は追加されません。プロジェクトで使う prop 名に合わせて型宣言を読み込みます。

標準の `sx` を使う場合は、パッケージ付属の型宣言を参照します。`src/` があればその中に、なければプロジェクトのルートに次のファイルを置きます。

```ts title="plumeria.d.ts"
/// <reference types="@plumeria/core/sx" />
```

`styleProp` を `'classStyle'` などに変えた場合は、プラグインの設定と同じ名前で型を宣言します。[prop の型宣言](/ja/docs/api/types/Style#スタイリング-prop-を宣言する-declaring-the-styling-prop)
