Plumeria の資料は、Claude、Codex、Gemini、ChatGPT などが読める Markdown 形式でも公開しています。まずインストール手順を渡し、その後で作業に必要な資料を足してください。

<Callout type="info" title="最初にインストール手順を読む">
  エージェントにコードを頼む前に、必ずインストール手順を読ませてください。Plumeria のコードがどう動くかを理解するには、コンパイラとバンドラーの設定も必要です。
</Callout>

## 最初に渡す資料

次の文章をプロンプトに貼り付けてください。読む順番を指定し、コードを編集する前に一通りのルールを伝えられます。

```text title="Prompt for your coding agent"
コードを変更する前に、次の資料を順に読んでください。

1. インストール — https://plumeria.dev/docs/installation.md
2. AI 向けのルール — https://plumeria.dev/docs/ai.md
3. はじめにと基本の使い方 — https://plumeria.dev/docs.md

AI.md のルールに従ってください。設定を変える前に、プロジェクトで使っているバンドラーと
フレームワークを調べ、対応する手順を読んでください。Plumeria はビルド時にスタイルを CSS に変換します。
```

インストール手順ではパッケージ、スタイル用 prop の型宣言、ESLint、Next.js と Vite のコンパイラ設定を説明しています。それ以外のバンドラーを使う場合は、[バンドラーとの連携](#バンドラーとの連携)から該当する資料を足してください。

```text title="Minimum context"
https://plumeria.dev/docs/installation.md
https://plumeria.dev/docs/ai.md
https://plumeria.dev/docs.md
```

## Claude Code のプラグイン

Claude Code では、次のコマンドで GitHub リポジトリから Plumeria プラグインをインストールできます。

```text title="Claude Code"
/plugin marketplace add zss-labs/plumeria
/plugin install plumeria@plumeria
```

スキルは [AI.md](/ja/docs/ai) から生成されるので、ルールと内容がそろいます。Plumeria のスタイルを扱うときに Claude が読み込みます。
