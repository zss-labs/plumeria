`@plumeria/headlessui` は [Radix UI](https://www.radix-ui.com/) を使ったヘッドレス UI 部品のセットです。

## インストール

先に `@plumeria/core` とバンドラーを設定します。[インストール手順](/ja/docs/installation)

```sh title="Terminal"
pnpm i @plumeria/headlessui
```

## sx の仕組み

ビルドは依存パッケージである `@plumeria/headlessui` の中を解析しません。部品に渡す `sx` は、**部品が動く前に、呼び出し側で `className` と `style` に変換されます**。各部品は `sx` を処理せず、受け取った `...props` を内部の Radix UI の部品に渡します。

```tsx
import * as css from '@plumeria/core';
import { Dialog } from '@plumeria/headlessui';

const styles = css.create({
  primary: {
    padding: '10px',
    backgroundColor: 'navy',
    color: '#fff',
  },
});

// sx is compiled to className="xxxxxxxx" at this call site
<Dialog.Trigger sx={styles.primary}>Open</Dialog.Trigger>;
```

自作コンポーネントが受け取ったスタイルを、部品用のスタイルと重ねることもできます。

```tsx
export const OpenButton = ({ sx }: { sx?: css.Style }) => (
  <Dialog.Trigger sx={[styles.primary, sx]}>Open</Dialog.Trigger>
);
```
