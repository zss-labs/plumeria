---
title: "パッケージ一覧"
description: "Plumeria と一緒に使えるパッケージを紹介します。"
---

| パッケージ | 配布形式 | |
| :-- | :-- | :-- |
| [`@plumeria/wind`](/ja/docs/api/packages/wind) | ソース | Tailwind CSS のテーマの値を静的なトークンとして使う |
| [`@plumeria/headlessui`](/ja/docs/api/packages/headlessui) | ビルド済み | Radix UI のヘッドレス UI 部品 |
| [`@plumeria/inspector`](/ja/docs/api/packages/inspector) | ビルド済み | ブラウザーで要素に適用された Plumeria のルールを調べる |

ソースで配るパッケージは利用側のビルドで処理するので、アプリから渡すスタイルもビルド時に決まります。ビルド済みパッケージはどのアプリでも使えます。
