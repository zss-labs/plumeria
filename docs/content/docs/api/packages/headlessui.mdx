`@plumeria/headlessui` is a set of headless primitives built on [Radix UI](https://www.radix-ui.com/).

## Installation

Set up `@plumeria/core` and your bundler first; see [Installation](/docs/installation).

```sh title="Terminal"
pnpm i @plumeria/headlessui
```

## How sx works

`@plumeria/headlessui` is a dependency the build never scans, so an `sx` written on one of its components is **compiled to `className` and `style` at the call site**, before the component runs.
The components know nothing about `sx`; each one spreads `...props` onto the underlying Radix primitive.

```tsx
import * as css from '@plumeria/core';
import { Dialog } from '@plumeria/headlessui';

const styles = css.create({
  primary: {
    padding: '10px',
    backgroundColor: 'navy',
    color: '#fff',
  },
});

// sx is compiled to className="xxxxxxxx" at this call site
<Dialog.Trigger sx={styles.primary}>Open</Dialog.Trigger>;
```

A component of your own can compose a style it receives onto a part:

```tsx
export const OpenButton = ({ sx }: { sx?: css.Style }) => (
  <Dialog.Trigger sx={[styles.primary, sx]}>Open</Dialog.Trigger>
);
```
