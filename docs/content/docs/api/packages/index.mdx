---
title: 'Packages'
description: 'Packages built on Plumeria, shipped as source or as a dist.'
---

| Package | Ships as | |
| :-- | :-- | :-- |
| [`@plumeria/wind`](/docs/api/packages/wind) | Source | Tailwind CSS theme values as static tokens |
| [`@plumeria/headlessui`](/docs/api/packages/headlessui) | Dist | Headless primitives built on Radix UI |
| [`@plumeria/inspector`](/docs/api/packages/inspector) | Dist | The Plumeria rules applied to an element, in the browser |

A package shipped as source is compiled by the app's build, so a style the app passes
in is settled at build time. A dist works in any app.
