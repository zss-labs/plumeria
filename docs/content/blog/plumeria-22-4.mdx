## 22.3.4 and later
The later attribute wins:  

Starting in 22.3.4, a `className` or `style` attribute written after `sx` overrides the generated one instead of being merged into it. `<div sx={styles.text} className="banner" />` renders only `banner`. When `sx` comes after, as in `<div className="banner" sx={styles.text} />`, the generated `className` wins and `banner` is dropped. The same applies to a `className` or `style` passed to a styled component. To override a style, use `sx`.

## margin-trim

`marginTrim` accepts `none`, `block`, `block-start` and `block-end`. `in-flow` and `all` were removed from the spec, and the ESLint plugin now reports them.

## Shorter compiled output

22.4.1 shortens the output for common `sx` patterns without changing which styles apply. See [#735](https://github.com/zss-labs/plumeria/issues/735) / [#736](https://github.com/zss-labs/plumeria/pull/736) and [#737](https://github.com/zss-labs/plumeria/issues/737) / [#738](https://github.com/zss-labs/plumeria/pull/738).

## Release notes

## 22.4.2 (Nov 28, 2026)

- Fix: Accept percentages in logical margin and inset properties, blockSize and inlineSize in validate-values.

## 22.4.1 (Nov 28, 2026)

- Perf: Merge complementary branches on a stable condition into one class.
- Perf: Write the style selected by a stable condition directly.
- Perf: Read a module-level const after its declaration as stable.
- Perf: Evaluate the style steps in style when the class reads only stable conditions.
- Perf: Evaluate unused bound tests in a sequence instead of a helper.
- Perf: Read a stable argument in place even when a unit is added.
- Perf: Read a single leading test in place instead of a helper.
- Perf: Drop an overridden className or style written next to sx.
- Perf: Write a style guarded by `&&` on a stable condition directly, without a temporary.
- Perf: Write relayed variables of a stable call into each branch instead of copying a temporary.
- Perf: Fold static classes into a single lookup table so the receiving component joins no class strings at runtime.
- Refactor: Drop the parentheses around an identifier guard of a direct style.

## 22.4.0 (Nov 28, 2026)

- Update: Bump cssdefs to 1.1.0.
- Update: Accept `block`, `block-start` and `block-end` for marginTrim instead of `in-flow` and `all`.
